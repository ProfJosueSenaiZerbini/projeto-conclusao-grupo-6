Requisitos não funcionais:

Usabilidade:
RNF1. O sistema deverá possuir uma interface intuitiva, consistente e de fácil utilização.
RNF2. Tema claro e escuro.
RNF3. Navegação simples em até três cliques para funções principais.
RNF4. O sistema deverá oferecer suporte ao idioma português brasileiro, permitindo futura expansão para outros idiomas.
RNF5. O sistema deverá reduzir o consumo de dados móveis por meio do carregamento otimizado de imagens e arquivos de áudio.

Desempenho: 
RNF6. As pesquisas deverão apresentar resultados em até dois segundos em condições normais de utilização.
RNF7. Reprodução de áudio sem interrupções.
RNF8. Suporte a múltiplos usuários simultâneos.

Segurança:
RNF9. Autenticação por login seguro.
RNF10. Criptografia de senhas.
RNF11. Proteção de dados pessoais conforme a LGPD.
RNF12. Controle de permissões para diferentes tipos de usuários.

Disponibilidade:
RNF13. O sistema deverá permanecer disponível durante seu período de operação, minimizando indisponibilidades.
RNF14. Backup periódico dos dados.

Escalabilidade:
RNF15. Suportar aumento do número de usuários sem perda significativa de desempenho.

Compatibilidade:
RNF16. Funcionar nos principais navegadores.
RNF17. O sistema deverá adaptar sua interface automaticamente a smartphones, tablets e computadores, mantendo todas as funcionalidades disponíveis.

Qualidade do áudio:
RNF18. O sistema deverá reproduzir arquivos de áudio enviados pelos usuários com estabilidade.
RNF19. Ajuste automático conforme a conexão do usuário.

Acessibilidade:
RNF20. Compatibilidade com leitores de tela.
RNF21. Contraste adequado e navegação por teclado.
